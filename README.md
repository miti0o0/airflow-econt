# AirFlow – Товарителници Еконт (версия за телефон)

Уеб страница за създаване на товарителници в Еконт от телефон. Работи в браузъра и ползва
официалното JSON API на Еконт без вход, както формата на econt.com.

- Няма сървър и няма лични данни в кода. Данните на подателя се въвеждат веднъж в „Настройки“
  и се пазят само в браузъра на телефона (заедно с историята).
- Стартира в тестова среда. Реалната се избира от „Настройки“ → „Среда“.

## Публикуване в GitHub Pages

1. В github.com: хранилището → **Settings** → **Pages**.
2. **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)** → **Save**.
3. След около минута страницата е на `https://<потребител>.github.io/<хранилище>/`.

## На телефона

Отвори адреса в браузъра → меню → **„Добавяне към началния екран“**. Появява се иконка като на приложение.

## Файлове

`index.html` (екраните), `style.css` (изглед), `app.js` (логика и заявки към Еконт),
`manifest.json` и `icon-*.png` (иконка за началния екран).
